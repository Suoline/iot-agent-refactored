## 失败类型及统计结果

### 失败类型说明

| 失败层级 | 失败类型                           | 描述                                                         |
| -------- | ---------------------------------- | ------------------------------------------------------------ |
| 1        | 知识构建（Knowledge Construction） | 在事实提取、存储或更新过程中发生错误，例如设备 ID 与事实信息之间的映射不一致，或知识更新不准确。 |
| 2        | 路由决策（Routing Decision）       | 智能体错误地判断任务不需要设备调度，从而导致执行流程提前终止。 |
| 3        | 设备筛选（Device Selection）       | 智能体未能检索到正确的候选设备，例如遗漏目标设备或引入无关设备。 |
|          | 格式错误（Formatting）             | 候选设备集合未按照预定义格式返回，导致下游模块无法正确解析。 |
| 4        | 计划生成（Planning）               | 智能体未能结合用户偏好或上下文信息生成合理的设备控制计划。   |
| 5        | 参数错误（Parameter Error）        | 在设备操作过程中使用了错误参数，例如单位不一致（如将亮度值与百分比混用）。 |
|          | 实体选择错误（Entity Selection）   | 在执行过程中选择了错误的设备实体，导致偏离预期目标。         |
|          | 代码生成错误（Code Generation）    | 生成的执行代码存在逻辑或语法错误，例如在条件判断中使用了错误的状态变量。 |

## SAGE失败类型说明

------

### 表 III

**失败类别说明**
“失败层级（Failure Tiers）”这一列用于帮助理解失败类型的上下文。在大多数情况下，
发生在第 n 层的失败意味着更低层级的失败已被避免（4 = 最高层级，1 = 最低层级）

------

### 表格内容：

| 失败层级 (Failure Tier) | 失败类型 (Failure Type)           | 描述 (Description)                                           |
| ----------------------- | --------------------------------- | ------------------------------------------------------------ |
| 1                       | 格式问题（Formatting）            | 智能体未能遵循 ToolInstructions 要求的模板。                 |
|                         | 指令理解（Command understanding） | 智能体未能理解用户的请求。                                   |
| 2                       | 规划（Planning）                  | 智能体的计划不正确或缺少步骤。                               |
| 3                       | 计划执行（Plan execution）        | 智能体提出了正确的计划，但执行步骤缺失。                     |
|                         | 工具选择（Tool selection）        | 智能体在执行过程中选择了错误的工具。                         |
|                         | 工具参数填写（Tool population）   | 智能体为工具提供了错误的参数。                               |
|                         | API 请求（API request）           | 智能体发出了错误的 SmartThings API 请求（例如属性、命令或组件错误）。 |
|                         | 代码生成（Code writing）          | 智能体生成的代码无法正常运行。                               |
| 4                       | 工具故障（Faulty tool）           | 非智能体导致的失败（通常是设备消歧工具中的 VLM 失败）。      |
|                         | LLM 限制（LLM limitation）        | 大模型缺乏关键常识或受到上下文长度限制。                     |
|                         | 幻觉（Hallucination）             | 智能体虚构了不存在的概念（如设备、组件或用户需求）。         |
| NA                      | 其他（Other）                     | 所有其他类型的失败。                                         |
